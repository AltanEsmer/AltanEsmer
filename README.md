## Selected work

### Event Management System

*Private client work · Sole developer*

I designed, built, and deployed a production event management platform for a hotel, replacing an older system affected by scheduling conflicts and weak error handling. It gives staff a shared operational calendar, conflict detection, validation, role-based access, analytics, notifications, audit history, and bilingual workflows. The system has managed more than 500 real events in production.

**Stack:** React · Node.js · PostgreSQL · Auth0 · Nginx · PM2

### Esmer Market

*Client website · Sole designer and developer*

I created [Esmer Market's first professional online presence](https://esmermarket.com), giving the local grocery business a bilingual Turkish and English website for campaigns, customer reviews, store information, location, and direct enquiries.

**Stack:** Next.js · React · TypeScript · Tailwind CSS · Firebase · Netlify

[Visit website](https://esmermarket.com)

### 4ES Dash

A self-hostable [Steam statistics dashboard](https://4es-dash.vercel.app) for exploring playtime, achievements, library value, and long-term trends. It includes Steam authentication, scheduled data snapshots, multi-user support, and a documented deployment path.

**Stack:** Next.js · TypeScript · Prisma · PostgreSQL · Steam Web API · Vercel

[Live demo](https://4es-dash.vercel.app) · [Source code](https://github.com/AlesSystems/4ES-Dash)

### ASCII Art Generator

A privacy-first image-to-ASCII toolkit delivered as a [web application](https://asciart.vercel.app), command-line tool, and reusable TypeScript library. It handles color output, edge detection, dithering, and animated GIFs entirely on the user's machine.

**Stack:** TypeScript · Next.js · Canvas API · Web Workers · Sharp · Vitest

[Live demo](https://asciart.vercel.app) · [Source code](https://github.com/AlesSystems/ASCII-art-generator)
